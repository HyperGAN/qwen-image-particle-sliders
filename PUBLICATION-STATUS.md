# Publication and qualification status

The canonical Qwen Image 2.1 package uses shared core 0.15.2 and ParticleGAN
0.11.1. The [lifecycle guide](LIFECYCLE.md) documents the current software
entry points. The [strict native candidate](native-strict/README.md) and
[HNDL candidate](docs/hypergan-hndl-candidate.md) have separate packages.

CPU fixture checks cover the installed runtime. Pretrained image quality,
convergence and accelerator fit require qualification with the current source.

The [original publication and its 26-case CPU receipt](https://github.com/HyperGAN/qwen-image-particle-sliders/blob/7ea24d2072324bb707e0f7ceb6e5f30d048dff19/PUBLICATION-STATUS.md)
remain available at the original revision.
